# Object orientation in functions
## [[6.5, 6.6, 6.7]]

- When we give values to a [[Functions| function]] as [[parameter]], what happens is that the [[arguments]] in the function point to the same [[id]] as the [[id]] of the [[variable]] in the [[__main__]] block.[[Aliasing]]
	- This kind of [[Aliasing]] even happens for immutable types.
