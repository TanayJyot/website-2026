# data classes
## [[10.1, 10.2, 10.3]]
### [[interface]]
- Everything that we write in the dataclass is part of the [[interface]] but of course whatever is in [[@dataclass]] won’t be a part of it. 

### Creating a data class 
- To create a [[dataclass]] you set up an [[initializer]]
- You use [[self]] in the dataclass. 
### Behind the Scenes
- A new [[object]] is created.
- The [[helper function]] [[__init__]] in the [[object]] is executed.
- The [[object]] gains values and these values are returned.
