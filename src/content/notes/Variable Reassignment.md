# Variable Reassignment
- Variable assignment occurs top down so if you change values of variables later it does not effect the variables earlier
> an assignment statement `<name> = ...` only changes what object the variable `<name>` refers to, but never changes any other variables.
## [[6.5, 6.6, 6.7]]
> Statements of the form `<name> = _______` _reassign_ the variable `<name>`
