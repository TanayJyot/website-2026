# value equality
## [[6.5, 6.6, 6.7]]
[[== Operator]] checks whether two elements have the same value and doesn’t care about the [[id]][^1]

[^1]: Can there be a case where objects have the same id but not the same value? #csc110/answered No this is not possible since [[identity equality]] is a stronger equality and ensures both.
