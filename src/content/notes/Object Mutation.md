# Object Mutation
- The ability to change the values in a program without changing the [[id]] or the [[Data type]]. 
- You should avoid using object mutation and [[Variable Reassignment]] unless necessary because then you need to keep track of the steps happening in your code.
## [[6.5, 6.6, 6.7]]
> assignment statements of the form `<name>[<index>] = ______` _mutate_ the list object that `<name>` currently refers to.
