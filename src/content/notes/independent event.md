# independent event
##

$$P(A|B) = P(A) \land P(B|A) = P(A)$$


- This is not the same as [[mutually exclusive event]], since $\frac{P(\text{Ace of Spades})}{P(\text{Ace})}$ is the same as the probability of getting a $P(\text{Ace of Spades})$
-  It also follows that: $$P(A \cap B) = P(A)P(B)$$
