# machine learning model
## The What?
- a model that adapts its behaviour based on new inputs to give more accurate results.
- when machine learning gives an output in the form of a function then we call it a machine learning model. 
- A machine learning model would take the [[mapping space]] and *learn* what the function would be from the mapping space. 
- [[Supervised Machine Learning]]
- [[unsupervised learning]]
- [[semi-supervised learning]]
___
- [[classification model]]
- [[regression model]]

## The How?

- A Machine learning model is restricted to the [[data]], it cannot do anything that is not a part of the data it is bounded by.
- So we need to choose the data wisely because it may contain too much noise which affects the output from the machine learning algorithm
