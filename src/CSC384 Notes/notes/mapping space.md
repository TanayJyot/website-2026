# mapping space
##
- when you do [[mapping]] then you can calculate the space that the operation would occupy which will be the mapping space.
- So if you have an input of a 3 pixel image where each pixel can be anything between (0 to 255) and the output is a boolean which can be 0 or 1 then the mapping space would be $(256×256×256)×2$.
